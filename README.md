# Prompt Template Workbench
提示词模板管理系统｜前后端分离全栈实战项目

## 项目简介
面向AI开发场景搭建的Web管理平台，用于统一管理各类提示词模板。
项目采用前后端分离架构，包含前端交互界面与后端接口服务，支持本地完整部署运行，作为全栈开发实战项目。

## 技术栈
前端：Vue3 + Vite
后端：Python
工具：Git、GitHub

## 目录结构
- frontend 前端工程
- backend 后端接口服务

## 功能
- 新增、保存提示词模板
- 编辑、删除模板内容
- 关键词检索查询
- 数据持久化存储
- 前后端接口联调
